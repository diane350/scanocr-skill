# transcribing-scanned-readings

A Claude skill that turns a scanned reading into clean text (`.md`) and a searchable PDF
for Zotero, with page numbers and linked footnotes.

**Install:** download `transcribing-scanned-readings.zip` and upload it in Claude under
**Customize > Skills**. Code execution must be on in your settings.

**Updates:** each chat fetches the latest code from this repository, so code fixes arrive
on their own. GitHub must be allowed in code execution's network settings; otherwise the
code inside the zip is used. When the skill's instructions change, Claude says so: then
download the zip again and upload it to replace the old one.

This repository is updated automatically from a private one; changes made here are overwritten.
